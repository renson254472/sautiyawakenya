Responsive PR, social media strategy and communications website.

## Hosting
Use Cloudflare Pages or another business-friendly static host. Connect this repository, choose no framework, no build command, and the repository root as output.

## Contact
The website uses sautiyawakenya0@gmail.com. The enquiry form prepares a mailto draft; it does not submit or store enquiries.
